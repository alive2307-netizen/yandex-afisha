\# Исследование лояльности пользователей Яндекс Афиши



Проект посвящён исследовательскому анализу данных (EDA) поведения пользователей сервиса Яндекс Афиша с целью выявления ключевых факторов удержания (retention) и формирования ядра постоянных покупателей.



\## Стек технологий

\* \*\*Python 3.9+\*\*, \*\*Jupyter Notebook\*\*

\* \*\*Анализ данных и вычисления:\*\* `pandas`, `numpy`, `scipy`

\* \*\*Визуализация:\*\* `matplotlib`, `seaborn`

\* \*\*Корреляционный анализ:\*\* `phik`

\* \*\*Базы данных и безопасность:\*\* `SQLAlchemy`, `psycopg2-binary`, `python-dotenv`



\## Этапы выполнения проекта

1\. \*\*Выгрузка данных из PostgreSQL:\*\* формирование выборки транзакций с расчётом временных интервалов между заказами (`days\_since\_prev`).

2\. \*\*Предобработка данных:\*\*

&#x20;  \* Конвертация валют (KZT в RUB по официальному курсу ЦБ на дату транзакции).

&#x20;  \* Оптимизация типов данных (downcasting памяти).

&#x20;  \* Фильтрация некорректных значений и технических клик-дубликатов с лагом < 60 сек.

&#x20;  \* Отсечение выбросов по 99-му перцентилю выручки.

3\. \*\*Построение профилей пользователей (`user\_profile`):\*\*

&#x20;  \* Расчёт агрегированных поведенческих признаков (средний чек, среднее число билетов, средний интервал возврата).

&#x20;  \* Отсечение аномальной активности по 95-му перцентилю заказов.

4\. \*\*Исследовательский анализ и проверка гипотез:\*\*

&#x20;  \* Анализ конверсии в повторные заказы в разрезе жанров, устройств, регионов и операторов.

&#x20;  \* Оценка влияния величины среднего чека и размера корзины.

&#x20;  \* Анализ временных лагов и дней недели.

&#x20;  \* Построение корреляционных матриц $\\phi\_k$.



\## Ключевые выводы

\* \*\*Точки входа:\*\* Наибольшую лояльность при первом визите формируют жанры \*\*«Театр»\*\* (61.8% возвратов) и \*\*«Выставки»\*\* (63.2%). Направление «Спорт» отстаёт по показателю удержания (53.7%).

\* \*\*Оптимальный ценовой коридор:\*\* Максимальный уровень повторных покупок (71–72%) сосредоточен в диапазоне среднего чека \*\*400–800 руб.\*\*

\* \*\*Размер корзины:\*\* Парные заказы (\*\*2–3 билета\*\*) обеспечивают наивысшую возвратность (71.3%), тогда как массовые заказы (5+ билетов) носят разовый характер (18.9% возвратов).

\* \*\*Главный драйвер лояльности:\*\* Интервал между покупками показывает сильную корреляцию с числом заказов ($\\phi\_k = 0.47$ в целом, $\\phi\_k = 0.71$ в когорте 5+ заказов). Критическое окно возврата — \*\*7–14 дней\*\*.
